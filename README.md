# App Perpustakaan

## Deskripsi Aplikasi

App Perpustakaan adalah aplikasi berbasis web yang digunakan untuk membantu pengelolaan data perpustakaan. Aplikasi ini dikembangkan menggunakan framework Laravel 12.

## Tujuan Aplikasi

Tujuan dari aplikasi ini adalah untuk mempermudah pengelolaan data perpustakaan secara digital, seperti pengelolaan buku, anggota, dan proses peminjaman.
